# Deploy Your Website - Share with Clients

## 🚀 **Option 1: Netlify Drop (FASTEST - 2 Minutes)**

### No Account Needed - Perfect for Prototypes

1. **Go to:** https://app.netlify.com/drop

2. **Drag and Drop:**
   - Simply drag your entire `Sauna Site` folder onto the page
   - Or click and browse to select the folder

3. **Wait 30 seconds:**
   - Netlify automatically deploys your site
   - You'll see a live URL like: `random-name-12345.netlify.app`

4. **Share the URL:**
   - Copy the URL
   - Send it to your client
   - They can view it on any device, anywhere!

5. **Update Changes:**
   - Make changes locally
   - Drag the folder again to Netlify Drop
   - Same URL, updated content!

**✅ Pros:**
- Instant deployment
- Free
- No account required
- Shareable URL
- Works on mobile/desktop

**⚠️ Cons:**
- URL changes each time you drag (unless you create account)

---

## 🌐 **Option 2: Netlify with Account (Best for Ongoing Updates)**

### Keep Same URL Every Time

1. **Create Free Account:**
   - Go to https://www.netlify.com
   - Sign up (free)

2. **Deploy:**
   - Drag folder to Netlify dashboard
   - Get permanent URL: `your-name.netlify.app`
   - Or connect to GitHub for automatic updates

3. **Custom Domain (Optional):**
   - Add your own domain later
   - Free SSL certificate included

---

## 📦 **Option 3: GitHub Pages (Free Hosting)**

1. **Create GitHub Account** (if you don't have one)

2. **Create Repository:**
   - Go to github.com
   - Click "New repository"
   - Name it: `nomad-steam-website`
   - Make it public

3. **Upload Files:**
   - Drag all your files into the repository
   - Commit changes

4. **Enable GitHub Pages:**
   - Go to Settings → Pages
   - Select `main` branch
   - Click Save

5. **Get Your URL:**
   - `yourusername.github.io/nomad-steam-website`
   - Takes 1-2 minutes to go live

---

## 🔗 **Option 4: Vercel (Alternative to Netlify)**

## 📱 **Testing on Mobile Before Sharing**

### View on Your Phone While on Localhost:

1. **Find your computer's IP:**
   ```powershell
   # Run in PowerShell
   ipconfig
   ```
   - Look for "IPv4 Address" (e.g., 192.168.1.100)

2. **Make sure you're on same WiFi:**
   - Phone and computer on same network

3. **On your phone browser:**
   - Go to: `http://192.168.1.100:8000`
   - Replace with your actual IP

4. **Test everything:**
   - Navigation
   - Forms
   - Mobile menu
   - All sections

## 🆘 **Troubleshooting**

**Site not loading?**
- Check all files uploaded correctly
- Ensure `index.html` is in root folder
- Wait 1-2 minutes for first deployment

**Want to update?**
- Make changes locally
- Drag folder to Netlify again
- Changes live in seconds

**Need custom domain?**
- Add in Netlify settings
- Point DNS to Netlify
- Free SSL included
